# Замер скорости интернета

Скрипт скачивает файл по переданной ссылке 10 раз подряд и выводит среднее
время запроса, общий объём данных и скорость скачивания.

## Запуск

Нужен Python 3.9+. Всё работает на стандартной библиотеке.

```bash
python speedtest.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

В примере используется адрес Cloudflare для замеров скорости. Параметр
`bytes=10000000` задаёт объём одного ответа — 10 МБ.
Можно передать свою прямую HTTP(S)-ссылку на большой файл, например картинку.
Путь к файлу на компьютере для замера интернета не подойдёт.
Если команда `python` не найдена, попробуйте `python3` или `py` на Windows.

По умолчанию таймаут — 30 секунд. Его можно изменить:

```bash
python speedtest.py "https://speed.cloudflare.com/__down?bytes=10000000" --timeout 60
```

Таймаут относится к ожиданию сетевой операции. Всё скачивание может занять
больше времени.

## Расчёт

Время замеряется через `perf_counter()`: от начала запроса до полного
скачивания файла, включая подключение и ожидание ответа сервера.
Следующий запрос начинается только после завершения предыдущего.

Среднее время — сумма времени всех запросов, делённая на 10.
Скорость считается так:

```text
МБ/с = всего скачано байт / суммарное время в секундах / 1 000 000
```

В задании единицы указаны как «мб/с», поэтому выводятся и МБ/с, и Мбит/с.
Для перевода в Мбит/с результат умножается на 8.

Файл читается блоками по 64 КиБ и не сохраняется. Объём считается по
полученным байтам. Если сервер прислал `Content-Length`, скрипт также
проверяет, что скачал весь заявленный объём.

При ошибке запроса, пустом или обнаруженном неполном ответе замер
останавливается с сообщением об ошибке и кодом выхода 1. Итоговая скорость
в этом случае не выводится.

HTTP 429 означает, что сервер ограничил частоту запросов. В таком случае
нужно подождать перед новым запуском или выбрать другой адрес. Увеличение
`--timeout` эту ошибку не исправит.

Результат зависит от выбранного сервера: если он отдаёт файл медленно,
быстрое подключение к интернету само по себе не поможет. И стоит помнить,
что файл скачивается десять раз — файл на 100 МБ даст около 1 ГБ трафика.
